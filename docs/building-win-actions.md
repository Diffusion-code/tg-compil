# Сборка Windows-клиента в GitHub Actions

## Однократная настройка

1. Получите собственные `api_id` и `api_hash` на https://my.telegram.org.
2. В репозитории откройте **Settings → Secrets and variables → Actions**.
3. Добавьте секреты `TDESKTOP_API_ID` и `TDESKTOP_API_HASH`. Не помещайте их в исходный код.

Сборка проверяет наличие секретов до загрузки зависимостей. Их значения не выводятся в журнал.

## Запуск

1. Откройте **Actions → Windows. → Run workflow**.
2. Дождитесь результата. Первая подготовка зависимостей занимает больше времени; следующие сборки используют кеши `ThirdParty`, `Libraries/win64` и `Qt`.
3. Скачайте артефакт `Telegram x64 qt6 Ninja Multi-Config` на странице успешной сборки. Он содержит `Telegram.exe` и хранится 30 дней.

Конфигурация: Windows x64, Qt 6, Release, Ninja Multi-Config. Автообновление выключено, чтобы официальный клиент не заменил эту сборку.

Кеш ускоряет повторную подготовку, но не является резервной копией. GitHub может удалить его; при изменении toolchain или зависимостей создаётся новый кеш. Не удаляйте исходники библиотек вручную: пересборка некоторых компонентов зависит от них.
